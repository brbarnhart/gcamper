# gcamper

Fiber photometry analysis toolkit (TDT-first).

Load TDT blocks into tidy session dataframes, compute regression-based ΔF/F, and extract event-aligned windows.

## Install

```bash
uv sync
```

## Quick start

```python
from gcamper import create_master_df, regression_based_dff
```
